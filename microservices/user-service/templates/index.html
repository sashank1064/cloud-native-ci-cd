Project Architecture

This repository carries the complete cloud-native path: infrastructure as code, image packaging, registry publishing, Kubernetes release management, and public traffic through an AWS load balancer.

Terraform Creates VPC networking, EKS, ECR, IAM roles, IRSA wiring, and supporting AWS resources.
Docker and ECR Builds this Flask service into an image and stores the deployable artifact in Amazon ECR.
Helm on EKS Runs replicated pods, injects environment values, and configures health and readiness probes.
ALB Ingress Routes live HTTP traffic through the AWS Load Balancer Controller to the Kubernetes service.

What This Demonstrates

When the app is deployed, this page acts as a visual smoke test for the running service and a quick explanation of the delivery system behind it.

Operational checks The `/health` and `/ready` endpoints support Kubernetes probes and load balancer health checks.
Release metadata The environment, version, hostname, and timestamp show which app instance served the request.
CI/CD friendly Tests, Docker build, Helm chart, and Terraform validation can all be wired into automated checks.
Demo business endpoint The `/users/demo` API returns sample user records so the service behaves like a small real microservice.
Structured request logs Every request emits method, path, status code, duration, service, and environment fields.
Deployment metadata Image tag, Git commit, build date, cluster, and region can be injected by Helm and CI/CD.
